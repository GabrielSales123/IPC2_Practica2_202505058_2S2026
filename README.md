## Reproductor Musical

Proyecto correspondiente a la **Práctica 2 de Introducción a la Programación y Computación 2 (IPC2)**.

## Descripción

Aplicación de escritorio desarrollada en **C# con Windows Forms** que permite gestionar y reproducir canciones mediante:

- Cola de reproducción implementada manualmente.

- Árbol binario de búsqueda para organizar y buscar canciones.

- Carga de canciones desde un archivo JSON.

- Cálculo del tiempo total de reproducción.

- Visualización de las estructuras mediante **Graphviz**.

## Tecnologías

- C#

- .NET

- Windows Forms

- Graphviz

- JSON

## Ejecución

Abrir la solución `ReproductorMusical.sln` en Visual Studio y ejecutar el proyecto.
